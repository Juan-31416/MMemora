# MindMapper v0.3 — Pre-release

**Status:** Pre-release

## English

### Summary

v0.3 improves the readability, customization, and navigation of mind maps while introducing English and Spanish language support.

### Added

- English and Spanish documentation.
- Multilanguage application support.
- Node icon options.
- Additional node color options.

### Improved

- **Search matching:** only the exact matching portion of a node's text is underlined. The rest of the node text is not underlined.
- **Radial view:** enhanced visualization behavior.
- **Node text display:** complete text is displayed inside the node.

### Upgrade notes

No migration steps are documented for this pre-release.

## Español

### Resumen

La v0.3 mejora la legibilidad, la personalización y la navegación de los mapas mentales, e incorpora soporte para español e inglés.

### Añadido

- Documentación en español e inglés.
- Soporte multilingüe en la aplicación.
- Opciones de iconos para los nodos.
- Opciones adicionales de color para los nodos.

### Mejorado

- **Coincidencias de búsqueda:** solo se subraya la parte de coincidencia exacta dentro del texto de un nodo. El resto del texto no se subraya.
- **Vista radial:** comportamiento de visualización mejorado.
- **Visualización del texto de nodo:** el texto completo se muestra dentro del nodo.

### Notas de actualización

No se documentan pasos de migración para esta pre-release.
